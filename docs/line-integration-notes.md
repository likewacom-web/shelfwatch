# บันทึกการเชื่อมต่อ LINE

> สถานะ: ผู้ใช้ยังไม่เลือกเปิดใช้การแจ้งเตือนผ่าน LINE

LINE Notify ยุติบริการเมื่อวันที่ 31 มีนาคม 2025 ดังนั้นหากเพิ่มการส่งข้อความไป LINE ในอนาคต ให้ใช้ LINE Messaging API ผ่าน LINE Official Account แทน เอกสารอ้างอิงระบุว่ามีปลายทางสำหรับส่งข้อความแบบ Push (`POST /v2/bot/message/push`) และต้องใช้ Channel access token
